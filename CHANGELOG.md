# Changelog

## 1.0.0

First version I would call finished enough for someone else to run.

- Recipes with parsed ingredients, sections, scaling, unit conversion, tags, favourites, notes, photos and times
- Week plan with servings per meal, copy last week, dinner ideas
- Shopping list from the plan, grouped by aisle, with a pantry and manual items
- Import from Markdown, recipe websites (schema.org) and JSON backups; Markdown export
- Cook mode, print layouts, dark mode, metric/US setting, stats page
- Docker image, `DATA_DIR`, backup script
- Fixed along the way: Sunday showing the next week, plural ingredient names not matching the pantry,
  deleted recipes staying in the plan, accent-sensitive search, link import following redirects to
  private addresses
